# કણસાગરા પરિવાર વંશ વૃક્ષ

GEDCOM ફાઇલ (`data/family.ged`) માંથી બનતી વંશ-વૃક્ષ વેબસાઇટ. ડેટા કોડથી અલગ છે, એટલે માહિતી અપડેટ કરવા માટે ફક્ત `family.ged` બદલવી પડે.

## ફાઇલોની રચના

```
├── index.html          ← વેબસાઇટનો કોડ (સામાન્ય રીતે બદલવાની જરૂર નથી)
├── data/
│   └── family.ged      ← પરિવારનો ડેટા (આ ફાઇલ બદલવાની છે)
├── .nojekyll
└── README.md
```

## પહેલી વાર GitHub પર મૂકવાની રીત

1. github.com પર નવી રેપોઝિટરી બનાવો (દા.ત. `kansagara-vansh`, Public).
2. રેપોઝિટરીમાં **Add file → Upload files** દબાવો.
3. આ ઝિપ ખોલીને `index.html`, `README.md`, `.nojekyll` અને આખું `data` ફોલ્ડર ખેંચીને મૂકો. **Commit changes** દબાવો.
4. **Settings → Pages** માં જાઓ. **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)** પસંદ કરી Save કરો.
5. 1–2 મિનિટ પછી સાઇટ આ સરનામે ખૂલશે: `https://<તમારું-યુઝરનેમ>.github.io/<રેપોઝિટરી-નામ>/`

## ડેટા અપડેટ કરવાની રીત (દર વખતે)

1. Family Echo માંથી નવી GEDCOM ફાઇલ Export કરો.
2. ફાઇલનું નામ બદલીને **`family.ged`** કરો.
3. GitHub રેપોઝિટરીમાં `data` ફોલ્ડર ખોલો. **Add file → Upload files** દબાવો, નવી `family.ged` મૂકો અને **Commit changes** દબાવો. એ જ નામની જૂની ફાઇલ આપમેળે બદલાઈ જશે.
4. 1–5 મિનિટમાં સાઇટ પર નવો ડેટા દેખાશે. ન દેખાય તો બ્રાઉઝરમાં રિફ્રેશ (Ctrl+F5) કરો.

> ફાઇલનું નામ અને સ્થાન બરાબર `data/family.ged` જ રહેવું જોઈએ. ફાઇલ UTF-8 એન્કોડિંગમાં હોવી જોઈએ (Family Echo એ જ આપે છે).

## કમ્પ્યુટર પર ચકાસવા માટે

`index.html` ને સીધું ડબલ-ક્લિક કરીને ખોલશો તો ડેટા લોડ નહીં થાય, કારણ કે બ્રાઉઝર file:// પરથી ફાઇલ વાંચવા દેતું નથી. ફોલ્ડરમાં ટર્મિનલ ખોલીને આ ચલાવો:

```
python -m http.server 8000
```

પછી બ્રાઉઝરમાં `http://localhost:8000` ખોલો.
